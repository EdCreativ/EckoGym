# EckoGym
Description
Ce projet est un site web moderne et structuré conçu pour une salle de sport fictive nommée EckoGym. L'objectif du site est de présenter de manière claire et attrayante les services, activités et formateurs disponibles afin de motiver et guider les utilisateurs vers une vie saine et active.
Le site contient plusieurs sections, chacune mettant en lumière un aspect clé de l'expérience EckoGym :
- Page d'accueil : Accueil chaleureux avec une image de fond dynamique et des messages inspirants tels que "Bienvenue chez EckoGym" et "Trouvez la voie saine".
- Programme populaire : Aperçu de trois activités principales (musculation, haltérophilie, combat corporel) avec images et boutons d'accès rapide.
- Le Club : Présentation générale du club et invitation à rejoindre la communauté.
- Nos Formateurs : Mise en avant d'un formateur, Shane Green, pour inciter à un accompagnement personnalisé.
- Exercices EckoGym : Liste variée d'exercices, accompagnée d'icônes et descriptions concises pour chaque activité.
- Témoignages : Récits d'expérience positive de clients satisfaits, renforçant la crédibilité et l'attrait du club.
- Pied de page : Informations supplémentaires, liens utiles et mentions légales.

Fonctionnalités
- Navigation intuitive et responsive.
- Interface visuellement attractive avec images captivantes.
- Appels à l'action clairs pour encourager l'engagement des utilisateurs.

Utilisation
Ce site peut être utilisé par les salles de sport pour :
- Promouvoir leurs services.
- Engager les visiteurs et augmenter le nombre d'adhérents.
- Partager des témoignages positifs pour établir la confiance.

Technologie
- HTML5 / CSS3 pour le contenu et le design.
- JavaScript pour une interactivité améliorée (si applicable).
